# 成果验收标准（38 周）

> 配套：[学习计划-Agent与具身智能-38周.md](学习计划-Agent与具身智能-38周.md)｜[每周学习材料-38周.md](每周学习材料-38周.md)｜[学习计划-进度追踪表.xlsx](学习计划-进度追踪表.xlsx)
> 这份文档只回答一个问题：**做到什么程度才算这一周没白过。**

## 一、先把「成果」定义清楚

成果不是「学了什么」，是**别人能验证的东西**。只有四种形态：

| 形态 | 例子 | 怎么验证 |
|:--|:--|:--|
| 能跑 | 一条命令、一个接口、一个脚本 | 别人 clone 下来执行不报错 |
| 能看 | 一张曲线图、一张对比表、一张 trace 截图 | 数据有出处，不是手画的 |
| 能读 | README、评测报告、设计文档 | 三个月后的你看得懂 |
| 能讲 | 3 分钟讲清取舍 | 不看稿、不被问倒 |

**关键判据**：任何一个数字，你都要能回答「这个数是怎么来的」。面试官只问这一句。

## 二、每天：一个成果 + 两个强制动作

### 每天必须有 1 个成果（三选一）

| 档位 | 标准 | 用时 | 常见样子 |
|:--|:--|:--|:--|
| 及格 | 读完 + 跑了最小例子 + 3 行笔记 | 1h | 一个能 print 出结果的脚本 |
| 良好 | 产物进了仓库，别人能照着跑 | 1.5h | 带 README 的小脚本 + 输出样例 |
| 优秀 | 顺手做了个「换成 X 会怎样」的小实验 | 2h | 两行对比数字，哪怕结论是「没差别」 |

### 两个强制动作（不做就算没学）

1. **一次 commit**：代码或笔记，进仓库。留在 notebook 里等于不存在。
2. **三行日志**：`做了什么` / `卡在哪` / `明天第一步`。写不满三行，说明今天没推进。

### 一天的收尾（10 分钟）

- 今天的产出能不能被截图放进周报？不能 → 明天补一个能跑的最小版本。
- 今天的「卡点」是知识缺口还是环境问题？环境问题当天解决，别带过夜。

## 三、每周：六件套 + 一张验收单

每周日填完这六项，才算交付：

| # | 件 | 判定 |
|:--|:--|:--|
| 1 | 代码 | 仓库有 commit，且能被别人跑起来 |
| 2 | 数字 | 至少一个指标（指标 / 耗时 / 成本 / 成功率） |
| 3 | 文档 | README 或笔记更新，含「已知限制」 |
| 4 | 图 | 一张能直接放进 PPT 的图 |
| 5 | 话 | 3 分钟讲清本周做了什么、为什么 |
| 6 | 复盘 | 5 行周报 + 自评 1–5 |

## 四、38 周成果清单

每周一行：一句话成果 → 证据 → 达标线 → 不合格的样子。

### W1｜10/19–10/25

**成果**：能用工程化方式调用 LLM，并说清 token 计费与首 token 延迟

- 证据：mini-llm-service 仓库首个 commit；`ask` 命令的录屏或 gif；一页笔记（流式与 SSE 的关系）
- 达标：`--stream` 逐字输出；`--debug` 打印 prompt/completion 两个 token 数；断网或超时 3 秒内报错且不崩
- 不合格：直接 print 整段返回；没有超时配置；token 数靠估

### W2｜10/26–11/01

**成果**：能交付一个「别人 clone 下来就能跑、能测」的服务

- 证据：/chat 服务 + 8 条 pytest + Dockerfile；README 里两条命令（build / run）
- 达标：`pytest -q` 全绿且不需要真 key（全 mock）；镜像 < 1.2GB；curl 拿到流式
- 不合格：测试要真 key、跑一次花两毛；Dockerfile 用 latest；没有 .dockerignore

### W3｜11/02–11/08

**成果**：能把 50 份 PDF 变成可检索、可引用答案的知识库

- 证据：索引构建脚本 + 5 问 5 答的引用截图 + 解析失败清单
- 达标：抽 3 个含表格的 PDF 人工核对不丢内容；每条答案附 chunk 原文；重建索引 < 5 分钟
- 不合格：只支持 txt；引用写「来自文档」这种废话；表格解析成一团

### W4｜11/09–11/15

**成果**：有一把尺子，能证明检索变好还是变坏

- 证据：30 条评测集（JSONL）+ 评测脚本 + 三种策略对比表
- 达标：人工确认 ≥20 条有效；一条命令跑完；表里同时有 Recall@5 与 MRR
- 不合格：让模型自己出题自己答；只写「感觉更准了」

### W5｜11/16–11/22

**成果**：能用改写、混合检索、重排把指标提上去，并说清各自代价

- 证据：四行消融表（基线 / +改写 / +混合 / +重排）+ 各方案延迟
- 达标：Recall@5 相对基线 ≥ +10%；每个改动的 P99 延迟增量有记录
- 不合格：全开但不做消融，说不出哪一步真的有用

### W6｜11/23–11/29

**成果**：能证明「答案没瞎编」，并把系统打包交付

- 证据：RAGAs 四指标报告（基线 vs 优化）+ Milvus 部署脚本 + v0.1 tag
- 达标：Faithfulness ≥ 0.85（达不到就写清基线并说明原因）；三条命令可复现
- 不合格：只贴一个分数，没有对照组

### W7｜11/30–12/06

**成果**：不看框架写出 150 行 Agent Loop，并能解释循环为什么停

- 证据：mini-agent 仓库 + 一次完整轨迹（JSONL，含每步耗时）
- 达标：3 个工具、最大步数、超时、解析失败重试齐全；轨迹能逐步回放
- 不合格：`while True` 没有上限；工具调用写死在 prompt 描述里

### W8｜12/07–12/13

**成果**：工具 30% 失败率下，Agent 仍能完成任务

- 证据：失败注入开关 + 三策略对比表（无重试 / 退避 / 降级）
- 达标：成功率 ≤70% → ≥95%；平均步数增幅 < 30%；成本不翻倍
- 不合格：只包了 try/except，没有降级路径

### W9｜12/14–12/20

**成果**：能力能以 MCP Server 形式被任意客户端复用

- 证据：Server 仓库 + 契约测试 + 客户端调用截图
- 达标：5 条契约用例通过（含非法参数）；错误信息可读；README 有 3 条示例
- 不合格：只能在自己脚本里 import，谈不上协议

### W10｜12/21–12/27

**成果**：Agent 跨会话记得用户，且上下文不炸

- 证据：记忆库 + 20 轮对话日志 + 压缩前后 token 对比
- 达标：第 2 天能召回偏好；20 轮后 token 增长 < 2 倍；10 条抽查召回准确率 ≥80%
- 不合格：把所有历史一股脑塞进 prompt

### W11｜12/28–01/03

**成果**：能让 Agent 停下来等人确认，也能读懂别人的 Harness

- 证据：research-agent 仓库 + 中断演示 + 一页拆解笔记
- 达标：高风险动作必须人工确认；进程被杀后能续跑；笔记指出 4 个机制的具体位置
- 不合格：「多 Agent 就是多写几个 prompt」

### W12｜01/04–01/10

**成果**：拿得出「优化前后」的硬指标

- 证据：火焰图 + QPS/P99 前后对比 + 改动清单
- 达标：QPS ≥3 倍或 P99 降 ≥50%，且成功率不变；每个改动能单独开关
- 不合格：换成更贵的模型充数，还说「性能提升了」

### W13｜01/11–01/17

**成果**：能把单次成本降下来，并说清代价

- 证据：成本拆解表（精确到分）+ 路由策略 + 质量对比
- 达标：单请求成本降 ≥40%；任务成功率下降 < 3%
- 不合格：只关缓存不测质量

### W14｜01/18–01/24

## 六、自评 1–5 分怎么打（别乱打分）

| 分 | 含义 | 判断依据 |
|:--|:--|:--|
| 1 | 看了，没动手 | 没有 commit |
| 2 | 抄通了，但不知道为什么 | 能跑，但改一个参数就崩 |
| 3 | 自己写出来了 | 不看教程能复现，能解释每行 |
| 4 | 能评测、能做消融 | 有对照组，说得出哪一步有用 |
| 5 | 能讲清取舍，能给别人讲明白 | 能回答「为什么不用另一种方案」 |

> 连续两周自评 ≤2 分：不是你不努力，是这一阶段的任务颗粒度不对——砍掉一个非核心项，重排。

## 七、不达标怎么办（降级规则）

| 情况 | 动作 |
|:--|:--|
| 某周只完成 3/6 件 | 保留代码 + 数字，砍掉文档和图，下周补 |
| 达标线差一点（如 Recall +8% 而非 +10%） | 如实记录，写清原因，继续走——不要为了凑数调参 |
| 整周没动 | 不补课，直接进下一周；把欠的那件写进「已知限制」 |
| 连续两周延期 | 砍掉本阶段的加分项（视频、博客），保主线 |

## 八、这份东西最终怎么用

面试时的标准句式：

> 「问题是什么 → 我怎么设计 → 怎么验证有效 → 哪一步失败了、为什么」。

你能把任意一周的「证据 + 达标线」讲成这四句，这一周就真的变成你的了。
